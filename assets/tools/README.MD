Country × Language Config
Overview

In our system, tools and translations vary depending on both the country and the language.
To support this, we define a Country × Language configuration that controls:

- Which tools are available in a given country.
- How the translations are displayed for each supported language in that country.
- This ensures that when a user switches language, the system still respects the country context.

Why This Approach?

- Country-specific tools – Some features are only available in certain countries.
- Localized translations – Each country may have unique phrasing, even for the same language.
